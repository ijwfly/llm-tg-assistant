# PHASE_6B_SESSION_DISCOVERY — тема = папка, обзор сессий машины, кнопки словами

Status: all phases done — тема = папка, обзор сессий машины, кнопки словами; tests green (168 passed); smoke — у пользователя

## Why

После фазы 6 пользователь не понял модель: сессии темы после `/new` выглядят чужими, `/sessions`
показывает только текущую папку, а кнопки `🔗`/`🌿` нечитаемы. Решение пользователя
(2026-09-03): **тема привязана к папке**; `/sessions` показывает сессии всей машины (в т.ч.
терминальные) и по клику создаёт тему под сессию и её папку; папку+сессию+тему можно завести
из бота с нуля; в кнопках — слова, не эмодзи.

## Verified facts

- Индекс сессий уже читает все проекты (`sessions.all_sessions`), `cwd` берётся из транскрипта.
- Создание тем прямым `createForumTopic` и переезд темы в папку сессии есть (фаза 6).

## Decisions

| Вопрос | Решение |
|---|---|
| Модель | Тема = папка (`topics.cwd`) + текущая сессия в ней. `/new` — новая сессия в той же папке (прошлая помечается как «эта тема, раньше»). `/cd` остаётся, но основной путь к другой папке — новая тема. |
| `/sessions` | Все сессии машины внутри `WORK_ROOT`, новые сверху, сессии папки темы — первыми; до 12 строк; строка `▸ <папка от WORK_ROOT> · <id8> · <давно> · «title» · <пометка>`; пометки: `эта тема`, `эта тема, раньше`, `тема «X»`, иначе пусто. Сессии вне `WORK_ROOT` не показываются, в подвале `ещё N вне WORK_ROOT`. |
| Кнопки строки | Одна кнопка на строку, словами: папка совпадает с папкой темы → `Продолжить здесь <id8>` (`rs`); иначе → `Новая тема <id8>` (`ns`) — создаёт тему с именем `<папка>: <title>`, `cwd` = папка сессии, сессия подхвачена (`session_resumable`). `Ветка <id8>` не в списке (есть `/branch <id>` и кнопка «Ветка» на карточке темы). |
| `/project` | `/project <алиас\|путь>` как раньше; `/project new <имя>` создаёт папку `NEW_PROJECTS_DIR/<имя>` (по умолчанию `WORK_ROOT`; имя без `/` и `..`), тему и свежую сессию; если папка есть — просто тема. |
| Прошлые сессии темы | `topics.settings.past_sessions` (до 20 id) пополняется в `/new`, `/cd`, `/resume`. |
| Кнопки | Все подписи словами: `Разрешить`, `Отклонить`, `Всегда: …`, `Отклонить и объяснить`, `Свой ответ`, `Готово`, `Выполнять, правки без вопросов`, `Выполнять, спрашивать про правки`, `Доработать план`, `Прервать`, `Повторить`, `Продолжить`, `Разрешать правки`, `Новый контекст`, `Стоп процесса`, `Сессии`, `Ветка`, `Обновить`, `Скрыть`. Эмодзи в кнопках нет. |
| Настройки | `NEW_PROJECTS_DIR: str \| None` (None → `WORK_ROOT`). |
