# llm-tg-assistant — коротко о проекте

Telegram-бот, который управляет сессиями Claude Code на сервере прямо из чата.
Одна тема форума (или тема в личном чате) = одна сессия `claude -p` в своей директории.

## Что умеет

- **Ходы из чата.** Текст, фото, альбом, файл, голос, форвард, reply и правка сообщения
  собираются в один ход Claude Code. Ответ приходит полноценным markdown, длинные ответы — файлом.
- **Живой прогресс.** В личке — редактируемый draft с размышлениями и следом инструментов,
  в группах — сообщение прогресса с кнопкой остановки.
- **Разрешения, вопросы, планы.** Бот выступает permission prompt tool для Claude Code:
  запрос на команду или правку показывается карточкой с диффом и кнопками
  (разрешить, отклонить, всегда, объяснить). Вопросы модели и планы — тоже карточки.
- **Управление сессией.** Новый контекст, стоп, отмена, повтор, смена директории,
  resume любой сессии (в том числе из терминала), fork в новую тему, тема на проект,
  переименование.
- **Гарантированная доставка.** Всё исходящее идёт через outbox в Postgres: порядок
  внутри темы, параллельность между темами, повторы при 429, переживает перезапуск.
- **Доступ только своим.** Списки разрешённых пользователей и чатов, чужие сообщения
  игнорируются молча.

## Стек

Python 3.12, aiogram 3.31, asyncpg, Postgres 16, docker-compose.
Claude Code запускается как процесс `claude -p` со stream-json; MCP-сервер для разрешений
написан на stdlib и общается с демоном через unix-сокет.

## Запуск

```
cp .env.example .env
cp settings_local.py.example settings_local.py   # токен и ALLOWED_USERS
docker compose up -d --build
```

Тесты: `bash scripts/test.sh` (e2e через реальный dispatcher и реальный Postgres, fake claude).

## Состояние

Готовы фазы 0–6 из 9: скелет, ходы, стриминг и кнопки, входной конвейер, разрешения,
сессии и темы. Впереди: настройки и голос (модель, усилие, персона, TTS, `/usage`),
дополнения (`/rewind`, `send_file`) и финальная документация с деплоем.
Дизайн — `specs/PROJECT_SPEC.md`, карта кода — `CLAUDE.md`.
